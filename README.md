# 🍳 포켓몬 슬립 요리 계산기 (PoSleep Recipe Calculator)

포켓몬 슬립(Pokémon Sleep)의 요리 재료를 관리하고, 지금 보유한 재료로 만들 수 있는 요리를 자동으로 계산해주는 웹 계산기입니다.

## 사용 방법

1. `index.html` 파일을 다운로드해서 브라우저(폰/PC 모두 가능)로 열면 바로 사용할 수 있습니다.
2. 상단에서 요리 종류(카레/스튜, 샐러드, 드링크/디저트)와 현재 냄비 용량을 설정합니다.
3. "요리 도감"에서 이미 해금한 요리인지 아직 못 만드는 요리(목표)인지 체크합니다.
4. "내 재료 입력"에서 보유 중인 재료 수량을 입력합니다. (재료를 클릭하면 미해금 상태로 잠금 처리할 수 있습니다.)
5. 오른쪽에 지금 바로 만들 수 있는 요리, 재료를 더 모아야 하는 요리, 대형 냄비(일요일)가 필요한 요리, 미해금 재료가 포함된 요리가 자동으로 분류되어 표시됩니다.

입력한 데이터는 브라우저의 로컬 저장소(localStorage)에 저장되어, 다시 접속해도 유지됩니다.

## 특징

- 인터넷 연결만 있으면 `index.html` 파일 하나만으로 바로 실행 가능 (재료 이미지는 GitHub 원본 주소를 직접 불러옵니다)
- 보유 재료 기준으로 제작 가능한 요리를 자동 계산
- 요리 도감 해금 여부에 따른 "🆕 도감 목표" 표시
- 냄비 용량을 초과하는 요리는 "일요일 대형 냄비 추천 목표"로 분류
